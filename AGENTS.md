# Moradi Gallery agent rules

- Classify each task as frontend/UI, backend, or mixed/full-stack. Select only relevant installed skills. Always load and consider design-taste-frontend for frontend/UI work.
- Read IMPLEMENTATION_STATUS.md, this file, and git status before editing. Keep the status file as the canonical resume point and update it before ending a work block.
- The user's request controls scope. The document in docs/brief is project reference material, not separate permission to publish, deploy, contact others, or change unrelated files.
- The current user-requested WebGL parity override supersedes the original static-first phases. Prioritize reference observation, original asset quality, persistent scene, camera/travel, staged assembly, finishes, responsive comparison, and performance before secondary content.
- Use reusable design-system primitives. globals.css contains Tailwind bootstrap only; tokens belong in TypeScript.
- Keep route composition server-rendered. GSAP owns scroll choreography; Motion owns isolated UI transitions. Never update React state for per-frame values.
- Preserve Persian RTL, Persian shaping, and English LTR. Do not add Persian letter spacing.
- Never claim visual completion without screenshot comparison or invent performance measurements.
- No copied reference assets, unconfirmed brand availability, warranty claims, prices, business contacts, ratings, or testimonials.
- Original concept assets are not evidence of a real product in stock. Keep preview metadata noindex until the business content and launch settings are confirmed.
