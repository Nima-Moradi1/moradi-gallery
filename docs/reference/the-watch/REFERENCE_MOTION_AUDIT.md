# Live reference motion audit

Observed 2026-09-13 in Codex Chromium. Source: https://thewatch.60fps.fr/

Full desktop and portrait scroll sequences were captured as dense PNG sequences; the browser exposes no video recorder. These are samples of live motion, not rendered source assets. Target percentages in filenames are requests; actual post-capture scroll positions are in desktop-progress.json/mobile-progress.json. Smooth scroll can lag a sample, so ranges are approximate and screenshots must be compared by visible phase. No private camera or shader source was inspected.

Desktop: 1440×900, initial document height 34625px. Portrait: 390×844, height 31582px after responsive recomposition. One continuous viewport canvas crosses editorial sections. Wide typography, metallic environment, dark movement interlude, exploded layers, macro dial/profile/strap, finish interaction and index/finale are visible. Desktop has more lateral breathing room; portrait has stacked copy, lower watch placements and tighter macro crops.
